First packaged release of RobBench: a native C++20 / Qt 6 Widgets / Vulkan 1.3 Roblox rig animation editor.

## Downloads

- **Windows x64 installer (.exe)**: installs RobBench and its bundled runtime dependencies.
- **Windows x64 portable (.zip)**: extract the complete archive and run `bin/RobBench.exe`.
- **RobBench.plugin.luau**: companion plugin source for importing `.rbanim` animations and exchanging exact Motor6D rigs with Studio. Install it as a local plugin in Roblox Studio; it is not a Creator Store listing.
- GitHub's source archives contain the complete source and build instructions.

Windows 10/11 x64 and a Vulkan 1.3-capable graphics driver are required. Visual Studio is not required to run the packaged application. Packages are not code signed.

## Included

- Native dark dockable editor, shaded Vulkan viewport, camera controls, picking and optional 4x MSAA.
- R6/R15 block authoring templates and custom Motor6D hierarchies through project import.
- Move/rotate/resize viewport gizmos, local/world joint axes, snapping, cancel and undo/redo.
- Joint posing, keyframes, multiple clips, timeline scrubbing, playback and quaternion interpolation.
- Atomic `.robbench` project saving/loading, recovery snapshots and versioned baked `.rbanim` export/import.
- Studio companion plugin for exact-pivot rig exchange, animation import and matching block-rig creation.

## Verification and current limits

The release workflow builds Windows Debug/Release, runs the core tests, generates ZIP/NSIS packages, and checks native Qt/runtime startup from the extracted portable ZIP. Linux tests additionally exercise both R6 and R15 native Vulkan editor workflows on software Vulkan.

This is an early development release, not the completed professional editor specification. Actual Windows GPU rendering and clean-machine interactive installation have not been verified. The Studio plugin has passed Luau syntax compilation, but installation, animation import and playback have not yet been tested in Roblox Studio. Existing character rigs must match part/joint names, hierarchy and C0/C1 pivots; automatic retargeting is not implemented. Roblox Studio cannot directly import `.rbanim` without the companion plugin.

Advanced mesh editing, texture painting, UV editing, graph editing, IK and physics-assisted animation are not implemented. See `docs/STATUS.md`, `docs/TRANSFORMS.md` and `docs/STUDIO_WORKFLOW.md` for exact capabilities and instructions.
