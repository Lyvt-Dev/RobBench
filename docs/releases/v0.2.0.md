RobBench 0.2.0 improves native timeline editing, character previews and model import.

## Changes

- Original purple RobBench logo, application/window icon and Windows installer icon.
- Timeline multi-selection with Ctrl/Shift-click, marquee selection and Ctrl+A. Drag keys together across tracks, copy/paste at the cursor, delete selected keys and scale selected timing. Timing edits are undoable and collisions are rejected without losing keys.
- Proportional retiming when changing animation duration, with an option to preserve absolute key times.
- Classic block-colored R6/R15 authoring templates with independently generated rounded heads and faces. These remain authoring templates; use Studio rig exchange for exact character pivots and dimensions.
- Static OBJ, FBX, glTF and GLB mesh import through Assimp. Geometry, normals, UV coordinates and diffuse/vertex colors survive project saving. Image texture rendering, skeletal mesh import and generic animation import are not included.
- Windows GUI executable without a console window. Only Release binaries are packaged.
- Manual update checker under Help, Windows installer downloads with size/SHA256 verification, and explicit installation confirmation. Private repositories can use an optional read token held only in memory.
- GitHub Actions generates SHA256SUMS for the Windows installer, portable archive and companion plugin. SHA256 is an integrity checksum, not Authenticode signing; Windows may still display SmartScreen warnings.

## Downloads and compatibility

Use the Windows x64 installer or extract the complete portable ZIP and run `bin/RobBench.exe`. A Vulkan 1.3 driver is required. Download SHA256SUMS alongside a package; PowerShell `Get-FileHash <file> -Algorithm SHA256` computes its checksum.

Native projects now use format version 2 to preserve mesh geometry. RobBench 0.2.0 reads version 1 projects; older versions cannot open version 2 projects. Animation interchange remains `.rbanim` version 1. Roblox Studio requires the supplied companion plugin to import it.

## Limits

This remains an early editor, not complete Roblox Animation Clip Editor parity. Graph/tangent editing, IK, texture painting, UV editing and advanced mesh editing remain unimplemented. Studio import and playback require manual verification in Roblox Studio; they have not been verified during this update. The updater's manifest parsing is covered by automated tests; an interactive Windows download/install cycle and actual Windows GPU rendering still require manual verification. See `docs/STATUS.md`.
